# LeadHunter AI Demo

A zero-API-cost prototype for testing real-estate lead qualification.

## Run
1. Install Python.
2. In this folder run:
   pip install -r requirements.txt
3. Then:
   streamlit run app.py

Open the local address shown by Streamlit.
